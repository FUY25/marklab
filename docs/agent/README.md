# MarkLab Agent Docs

This directory is the operating manual for local coding agents that work with MarkLab.

- [Agent guide](marklab-agent-guide.md)
- [Codex instructions](marklab-codex-instructions.md)
- [Claude Code instructions](marklab-claude-code-instructions.md)
- [Cursor instructions](marklab-cursor-instructions.md)

The short version: agents edit the local Markdown file on disk. MarkLab watches that file, syncs it into the browser editor, and exposes CLI commands for status, waiting, snapshots, sharing, and diagnostics.
